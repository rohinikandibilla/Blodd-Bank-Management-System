# 🩸 Blood Bank Management System

## Project Overview

The Blood Bank Management System is a DBMS project developed using MySQL to organize and manage blood bank information efficiently. It maintains records related to donors, recipients, donations, blood groups, and blood requests while ensuring data consistency through relational database concepts.

## Key Features

* Database design with tables and relationships
* Primary keys and foreign keys
* Data normalization up to Third Normal Form (3NF), where applicable
* CRUD operations (Create, Read, Update, Delete)
* SQL joins, aggregate functions, and subqueries
* Grouping and filtering of records
* Efficient management of donor and recipient information

## Technologies Used

* MySQL
* MySQL Workbench
* SQL
* DBMS concepts

## Objective

To demonstrate practical SQL and database management skills by designing a structured system that supports organized blood bank record management.

## Learning Outcomes

* Relational database design
* Data integrity and relationships
* Writing SQL queries
* Database normalization
* Managing and retrieving structured data

**Note:** This project is an academic database implementation and is not a production-ready medical system.
